# KDNA eCommerce Insights

WooCommerce profit, inventory, customer and marketing dashboard for wp-admin and Elementor, reusable across KDNA client stores.

The full project brief and staged Claude Code build plan are in [`docs/kdna-ecommerce-insights-brief.md`](docs/kdna-ecommerce-insights-brief.md) (Word version: `docs/kdna-ecommerce-insights-brief.docx`). Read it before starting any build session.

Packaging rule: no zip is built until the final stage, and the version number is always part of the zip file name, for example `kdna-ecommerce-insights-1.0.0.zip`.
